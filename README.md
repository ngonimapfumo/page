# Personal Landing Page

A clean, responsive personal portfolio website for showcasing projects, background, hobbies, and contact details.

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- Firebase Hosting (configuration included)

## Features

- Single-page layout with section navigation
- Responsive design for desktop and mobile
- Light/dark theme toggle with local preference persistence
- Scroll-reveal animations that respect reduced-motion preferences
- Project showcase cards with external links

## Project structure

- `/home/runner/work/page/page/index.html` – page content and sections
- `/home/runner/work/page/page/style.css` – styling, themes, and responsive rules
- `/home/runner/work/page/page/script.js` – theme toggle and scroll animations
- `/home/runner/work/page/page/assets/` – images and media used by the page
- `/home/runner/work/page/page/firebase.json` – Firebase Hosting config

## Run locally

Open `/home/runner/work/page/page/index.html` directly in your browser, or serve the folder with any static file server.

## Deployment

This repo includes Firebase Hosting configuration in `/home/runner/work/page/page/firebase.json`.
