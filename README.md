# Personal Landing Page

A responsive, dependency-free personal portfolio made for GitHub Pages.

## Customize

Open `index.html` and replace:
- `Your Name`
- `hello@example.com`
- GitHub and LinkedIn links
- Project names, descriptions and links

Then push the folder contents to a GitHub repository.

## GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will appear at `https://YOUR-USERNAME.github.io`.
